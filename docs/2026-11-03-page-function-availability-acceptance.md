## 验证边界

- 浏览器验收使用独立的 `localhost:5175` 前端、`127.0.0.1:8002` 后端和 `/private/tmp/availability-acceptance.sqlite` 临时 SQLite 库。库中仅有合成账号、两个合成项目、37 条任务、101 条音频和 21 条对比；三方 ASR 模型数为 0，ASR Worker 未运行，ZAP 关闭。验证完已停止隔离服务并删除临时库。
- 浏览器登录覆盖合成管理员、普通成员和只读成员；验证项目切换、页面刷新、历史浏览、创建前检查、ASR/ZAP 深链和依赖离线提示。只读成员打开创建表单时，因资源数为 0 而不能提交；对应的只读写入拒绝由服务测试覆盖。
- 没有对现存业务库写入或清理数据，没有调用收费模型、真实 ASR 服务、ZAP 扫描、通知发送或真实音频播放。
- 为了使临时 SQLite 浏览器库保持隔离，只建了本轮页面需要的表，没有跑应用全量迁移。全站工作台和安全页的部分非本轮表查询因此显示内部错误；ASR 历史、音频分页和 ZAP 状态请求可独立验证。该临时环境现象不视作正式 PostgreSQL 环境结论。

## 真实环境待补条件与范围外能力

部署环境需提供已迁移的 PostgreSQL、独立 ASR Worker 运行位与容器重启权限；三方评测需三个不同且已授权的 ASR 资源及对应修订/参数方案；DIARIZATION 需独立说话人模型；调参建议需批准的模型凭据；ZAP 需可达服务、凭据和明确授权的扫描目标。上述凭据和资源就绪后，按本记录中的未完成项补做真实集成验收。

报告明确列出的移动端能力、PDF/Word/Excel 报告导出等扩展未纳入本轮开发；本轮没有新增这些能力。已有 ASR 对比 JSON/CSV 导出不等同于报告导出能力。
