# UI 设计规范

## 布局

- 继续使用 React 18、Ant Design 5 和项目既有 PageContainer/PageHeader，不引入新 UI 技术栈。
- 管理端与工作台共享导航宽度、品牌区、菜单图标尺寸和选中反馈；桌面侧栏可折叠，断点以下收为覆盖式导航并提供遮罩。
- 业务页使用统一的标题、内容容器和操作区；筛选与操作可换行，不能把操作按钮挤出视口。
- 页面主要内容保持 `min-width: 0`；卡片使用 Ant Design 栅格，资源属性标签允许换行。

## 色彩和文字

- 采用 Ant Design 当前主题令牌：蓝色用于主要操作/选中，灰蓝作为页面底色，白色作为卡片和编辑区底色。
- 绿色表示成功或启用，红色表示错误/高风险，橙色表示警告/等待，灰色表示未设置或停用。
- 页面标题使用 `PageHeader` 的四级标题层级；正文和辅助信息使用 Ant Design 默认字号与 `Typography.Text` 层级。
- 保持系统默认字体栈，不用装饰性渐变、背景图或高密度阴影。

## 间距与容器

- 以 8px 为基础步长，主要使用 8、12、16、24px 间距。
- 卡片使用轻边框、白底和约 12px 圆角；优先通过间距和层级区分内容，不叠加厚重阴影。
- 筛选栏使用可换行布局；移动端搜索框占满可用宽度，筛选器可换行。

## 资源卡片

- 卡片优先显示名称、状态、类别/风险、真实关联数量和简短描述。
- 次要状态放入 Tag；长描述截断并可查看完整提示。
- 卡片可用键盘 Enter/空格打开详情；卡片内按钮单独执行操作，不触发外层打开行为。
- 仅当 API 返回真实数据时显示统计；缺少接口时展示空缺/能力说明。

## Drawer 与表单

- 详情从右侧打开并保留列表上下文；使用固定头部、Tab、可滚动正文和固定底部操作区。
- 普通管理详情宽度约 720–820px；长执行详情沿用共享组件原有 880px 默认值。小屏幕抽屉占满视口宽度。
- 编辑态关闭先提示放弃未保存内容；保存使用现有 API 和版本策略。
- 将“恢复默认”只放在后端确实支持该操作的工具配置中。
- API Key、Bearer Token 只显示“已配置/未配置”；编辑时仅允许重新写入，不能从接口回显明文。

## 状态与响应式

- 沿用 `LoadingState`、`ErrorState`、`EmptyState`，区分加载失败、空数据和无搜索结果。
- 目标视口：1440×900、1024×768、768×1024、390×844。
- 资源目录使用 24/12/8/1 列断点栅格规则；技能工作区在 760px 以下切为单列，文件树限制高度并独立滚动。
- 响应式验收以 `documentElement.scrollWidth <= innerWidth + 1` 检测横向溢出，并留存五个资源页的全页截图。
