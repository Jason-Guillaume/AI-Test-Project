# 业务流程优化报告

## 资源管理路径

### 模型资源

1. 按文本/ASR/说话人类别定位资源；搜索支持名称、供应商、模型标识、适配器。
2. 卡片进入 Drawer 查看元信息、连接安全摘要、参数方案、用途默认和历史修订。
3. “连接诊断”仍需用户明确确认真实模型调用；新连接通过创建不可变修订保存，旧任务快照不被覆盖。
4. 默认策略通过原接口写入，备用资源受同类别约束；ASR 自动备用仍被禁用。

### Agent

1. 默认卡片展示模型、主子关系、Skill、系统工具、MCP 工具和状态；搜索、测试类型、模型筛选和分页降低查找成本。
2. 在同一 Drawer 分 Tab 调整配置、提示词、技能/工具授权、触发器，不跳离列表。
3. 未保存时按 Drawer 关闭或底部关闭都会确认；保存继续走版本化 Agent API。
4. 保留树形关系、表格批量删除、回收站和历史恢复。

### MCP

1. 新增服务只登记地址与认证方式，不假装发现已经完成。
2. 管理员通过“连接并发现”取得真实工具、Schema 和注解。
3. 管理员保存审批白名单；只有连接状态、审批、只读标记和 Agent 绑定同时满足时，工具才进入 Agent 可选项。
4. Bearer Token 仅写入；更新留空保留服务端凭据，Drawer 文案解释密钥不会回显。

### Skill

1. 搜索或在目录树中选择 Skill，概览展示服务端的使用量与关联数据。
2. 选择文件后编辑器从同一个草稿文件映射加载；Markdown 可切换预览，文件切换不会沿用旧内容。
3. 保存前校验名称、非空 `SKILL.md`、文件数上限；后端写入成功返回新版本后刷新缓存。
4. 版本恢复覆盖工作区草稿时先确认，并由后端创建新的当前版本；删除仍走回收站生命周期。

### Tool

1. 使用搜索、分类、风险、启停和执行器状态筛选。
2. Drawer 将治理说明、只读运行字段、Agent 绑定分组展示；不可编辑执行器定义或权限边界。
3. 保存只更新当前 API 允许的治理字段；工具绑定带动 Agent 新版本，React Query 刷新相关目录。

## 数据一致性与风险控制

- 新增/更新/删除/恢复继续调用既有 FastAPI 端点；操作成功后失效 `agent-governance`、`model-center`、`recycle-bin` 对应查询缓存。
- 不引入静态模拟运行数据，不创建不存在的 API/权限行为。
- 软删除、批量回收、拒绝删除被引用资源、版本恢复均复用原后端实现。
- 本次后端修正仅调整 Alembic 初始基线以保留历史迁移职责；没有改变现有数据库 schema，也没有增加业务 API。
