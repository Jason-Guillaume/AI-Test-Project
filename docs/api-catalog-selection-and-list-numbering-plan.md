# 接口管理交互与全项目列表序号优化计划

本计划基于当前工作区源码。视觉尺寸为设计目标，实施前应在浏览器记录现状。优先完成“找到未分类接口 → 勾选本页 → 确认删除 → 核对结果”的完整路径，再推广序号规则。

## 第一阶段 · 目录选择与批量删除

主要入口为 `frontend/src/pages/console/ApiCatalog/ModuleTree.tsx`、`ModuleApiList.tsx`、`index.tsx` 和同目录的 `ApiCatalog.css`。目前普通模块的复选框位于行尾操作区，默认模块跳过该区域，空的默认模块还可能被目录过滤。右侧列表已有关键词、方法、状态筛选和批量删除回执。

| 入口 | 目标行为 |
| --- | --- |
| 普通模块 | 在树最左侧预留固定选择列。框体 22 × 22 px，点击区域至少 36 × 36 px。缩进从展开箭头开始。点击框只勾选，点击箭头只展开，点击名称打开该模块列表。 |
| 未分类 | 常显，包括接口数为零时。点击名称筛选未分类接口。复选框的可访问名称为“选择本页未分类接口”，勾选时显示该列表并选中当前筛选下的本页数据，部分选中显示半选。加载期间及空页禁用，系统目录本身不可删除。 |
| 模块批量操作 | 目录顶部显示已选模块数、清除选择、删除模块。复用模块删除影响预览，按实际子树去重显示模块和接口数，明确影响折叠及筛选外的子项。预览失败时允许重试。 |
| 接口批量操作 | 表头复选框选择本页，接口表左侧各行与表头统一尺寸。批量操作条显示接口数。翻页、切换模块、项目或筛选条件时清空选择。两类选择互斥，若切换会丢弃已有勾选，提示用户确认切换。 |
| 删除回执 | 提交中禁用重复操作。接口批删允许部分成功，刷新列表和目录计数，失败项保留勾选，通过名称、路径和原因定位。末页删空时回到有效页。模块删除后关闭已删除资源的详情。 |

## 第二阶段 · 页面展示

桌面保留目录与内容双栏，右侧标题展示当前模块路径及接口数。筛选项与重置按钮集中在表格上方。名称、方法和路径优先展示，长路径可查看全文和复制。低频目录操作收进行尾菜单，支持键盘打开。窄屏用“切换目录”打开抽屉，选中模块后返回接口列表。模块为空时提供新建或导入入口；筛选无结果时提供清除筛选入口。用浅色、深色及窄屏分别核对焦点、选中态和长文本。

## 第三阶段 · 全项目列表序号

1. 盘点管理端、控制台及其他可见列表，覆盖普通表格、弹窗、抽屉、子表和卡片。检查绑定主键的“ID”“编号”列、行标题中的 `#ID` 及自定义渲染。已知入口包括项目、缺陷、Mock、测试用例、套件、计划、执行记录、数据池和通知渠道。记录每处的分页方式和展示用途。
2. 在共享表格附近提供可复用的“序号”列计算，供 `frontend/src/shared/ui/ResourceTable.tsx` 的调用方和直接使用 Ant Design 表格的页面共用。按筛选与排序后的结果编号。服务端分页用 `(页码 − 1) × 每页条数 + 页内索引 + 1`；前端分页按排序、过滤后的完整结果位置取值，防止重复叠加偏移。无分页列表及各独立子列表从 1 开始。
3. 行标识、勾选集合、详情路由和写请求使用稳定资源 ID。关联资源显示名称或路径；用户用于追踪的业务编号保留。删除、筛选和排序后重新计算序号，无需数据库迁移。
4. 对照盘点逐项复查。特别注意测试用例中的“编号”及正在修改的缺陷、执行历史页面，合并时保留工作区已有修改。

## 验收与交付

| 场景 | 通过条件 |
| --- | --- |
| 目录与未分类 | 鼠标和键盘均可分别展开、浏览、勾选。未分类为空时可见，非空时只选中本页匹配接口。切换项目不残留选择。 |
| 删除范围 | 父子模块同时勾选时预览去重；取消后数据完整。接口存在引用导致部分失败时，回执数与刷新结果一致，重复点击只提交一次。 |
| 全项目序号 | 23 条数据每页 10 条，三页分别为 1–10、11–20、21–23。筛选剩 4 条时显示 1–4。倒序、改变页容量和删空末页后编号正确，点击同一条记录的详情、编辑或删除均命中真实记录。 |
| 展示及成本 | 桌面和窄屏都可看到当前范围、勾选数量和操作入口。以相同数据和缓存条件记录切换模块到列表可用的耗时与请求数；勾选本页无需下载其他页。 |

实施后按前端目录约定运行类型检查、lint、测试和相关 Playwright 场景，并验证构建。交付时附覆盖页面清单、代表性截图、测试结果和未验证项。删除场景使用隔离测试数据。
