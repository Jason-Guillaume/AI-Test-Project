## 1. 结论摘要

本轮复扫新增 **2 项 P2 问题**，加上首轮遗留的 `DEP-001`，累计跟踪 **3 项 P2**：分页与当前工作树中的固定数据库样例已修复，依赖风险仍开放；未确认 P0/P1 问题。类型分布为性能 / 数据完整性 1 项、敏感配置 1 项、依赖安全 1 项。

## 4. 问题清单

### RESCAN-001 — 批量分页请求绕过安全上限

- **分类 / 严重度 / 优先级**：性能与功能完整性 / 中 / P2
- **模块**：接口目录、统一任务、控制台项目选择器
- **状态**：扫描基线静态确认；本分支已修复并通过前端构建、类型检查与 Lint；大数据量浏览器场景未动态复现
- **证据位置**：
  - 扫描基线 `b5b65b9` 中，`ModuleTree.tsx`、`TaskCreateModal.tsx` 与 `ConsoleLayout.tsx` 根据总数或短页终止条件自行收集全部页面。
  - 当前修复位置：`frontend/src/pages/console/ApiCatalog/ModuleTree.tsx`、`frontend/src/components/tasks/TaskCreateModal.tsx`、`frontend/src/layouts/ConsoleLayout.tsx`；复用 `frontend/src/api/pagination.ts` 的 50 页 / 5000 条上限。Web 用例 API 增加页大小参数，测试管理裸数组接口使用有界数组收集器。
  - 扫描基线时 `frontend/src/api/pagination.ts:1-51` 已提供 50 页 / 5000 条上限，但上述调用点没有复用。
  - 当前工作树调用均使用该工具；代码证据见 §10。
- **影响与复现**：在扫描基线中，创建大量接口、项目、用例或登录态后打开接口树、任务创建弹窗或控制台项目选择器，会触发随 `total` 增长的额外请求；大数据量影响属于静态风险，未动态量测延迟或内存。
- **后续建议**：可进一步为大型树和候选列表增加服务端搜索 / 按需分页，并补充超过 5000 条、请求失败和分页数据变化的组件级回归测试。

### RESCAN-002 — 跟踪文档残留数据库样例凭据

- **分类 / 严重度 / 优先级**：敏感信息与文档配置 / 中（值是否有效未知）/ P2
- **模块**：本地启动文档、开发规范、测试数据
- **状态**：扫描基线静态确认；本分支已从文档与测试样例移除固定口令字面量。凭据可用性与是否曾用于真实环境仍待验证。
- **证据位置**：
  - 扫描基线中 `local-startup-guide.md:150` 与 `.claude/skills/develop-this-project/SKILL.md:475` 指向同一固定数据库凭据；`backend/tests/test_18_test_data_crud.py` 也将该字面量作为目标数据库 CRUD 测试输入。
  - 当前修复位置：`local-startup-guide.md` 改为要求核对显式配置；开发规范注明隔离测试库和环境变量要求；测试 CRUD 使用明确的虚构值；`backend/tests/test_01_schema_and_seed.py` 从测试环境读取数据库密码进行输出脱敏断言。
  - `compose.yaml:7-12` 当前要求显式提供 `POSTGRES_USER`、`POSTGRES_PASSWORD`、`POSTGRES_DB`，并将宿主机端口绑定到 `127.0.0.1`；与启动指南的固定凭据说明不一致。
- **影响与复现**：扫描基线中的跟踪文件包含数据库样例凭据；启动文档可能诱导开发者复用旧口令，或导致依照文档启动失败。当前 Compose 不再接受该默认值，且本轮已清除当前工作树中的固定字面量；没有证据表明样例能认证当前数据库。未检查部署环境或真实凭据库。
- **后续建议**：由环境所有者确认旧值是否曾用于共享数据库，若是则轮换；可将密钥扫描纳入仓库门禁。历史 Git 对象未扫描或改写。
