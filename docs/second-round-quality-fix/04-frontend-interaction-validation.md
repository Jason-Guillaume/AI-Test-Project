## 交互改动核验范围

- 模型诊断在没有项目上下文时要求显式选项目；仅列 owner/editor 角色项目，提交时再次核对表单值与项目列表。ASR/说话人音频跟随所选项目查询，切换项目清空音频选择并移除旧项目音频查询缓存。
- 页面打开、保存修订或参数方案均不触发真实模型调用。请求仅由用户点击触发；提交前必须勾选 `confirm_model_call`，并使用同步 in-flight guard 与按钮 loading 禁止重复提交。
- 详情抽屉按 resource ID 派生最新查询数据，刷新期间展示加载态；项目/类别变化及资源消失后关闭。
- Agent 与模型卡片由可聚焦的显式操作按钮承载详情、编辑、诊断和删除动作，整卡不再拦截键盘事件。
