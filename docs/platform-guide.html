01 / OVERVIEW

平台概览

本项目是一个前后端分离的测试开发平台，以组织和项目为管理边界，集中管理接口、测试资产、缺陷、报告及相关配置，并提供 AI 智能体、Web UI、数据、Mock、安全测试和语音评测等工作入口。

平台管理

用户、组织、项目、模型、环境及智能体资源的管理入口。

测试资产

围绕项目组织接口、业务、用例、套件、计划、报告与缺陷。

智能能力

提供智能体、知识、Skill 和工具相关入口，具体能力依赖配置与权限。

专项工作区

覆盖测试数据、Mock、Web UI、安全测试与 ASR 调优等场景。

本文依据当前仓库的代码结构、路由和已有文档编写；页面可见性、实际数据和外部服务可用性取决于部署配置及账号权限。

03 / GETTING STARTED

启动与访问

本地联调需要 Python 3.11+、Node.js 22.12+ 和 PostgreSQL 16。首次使用需准备数据库，安装前后端依赖，配置后端环境变量，并完成数据库迁移和管理员初始化。详细步骤以 启动指南 为准。

日常启动

# 终端 1：后端
cd backend
.venv/bin/uvicorn app.main:app --reload --port 8001

# 终端 2：前端
cd frontend
npm run dev
服务默认地址说明
平台前端http://localhost:5173登录后进入控制台或管理端
后端 APIhttp://127.0.0.1:8001业务接口使用 /api/v1 前缀
API 文档http://127.0.0.1:8001/docs查看接口定义
平台数据库127.0.0.1:5432本地 PostgreSQL 默认端口

05 / WORKFLOW

常见使用路径

登录平台→进入组织与项目→维护接口和测试资产→组织套件与计划→查看报告与缺陷
  1. 准备组织与项目：管理员或有权限的成员维护组织、项目及成员；使用者进入自己可访问的项目。
  2. 整理测试资产：根据实际项目维护接口目录、业务信息及测试用例，并用套件和计划组织测试内容。
  3. 查看结果与跟踪问题：在报告与缺陷页面查看已有记录，结合项目上下文跟进问题。
  4. 按需进入专项工作区：根据需要使用测试数据、Mock、Web UI、智能体或 ASR 等页面；相关外部依赖需预先配置。
06 / CONFIGURATION

配置与权限

基础配置

后端配置模板位于 backend/.env.example。本地运行至少需要配置 DATABASE_URL 和满足启动要求的 SECRET_KEY；本地 HTTP 开发时按启动指南设置 AUTH_COOKIE_SECURE=false。模型、通知或其他外部服务按实际场景配置。

前端开发服务器默认将 /api 请求代理到后端；后端端口不同时，可通过 VITE_API_PROXY_TARGET 调整目标。数据库结构通过 Alembic 迁移维护。

访问边界

平台区分平台角色、组织成员角色和项目成员角色。平台管理页面和项目资源需要对应权限；项目访问同时受组织边界与项目身份约束。服务端执行权限判断，页面是否展示操作入口不能代替授权。

真实密钥、数据库密码和第三方凭据应保存在本地环境配置或部署密钥系统中，不写入共享文档或代码仓库。
07 / ARCHITECTURE

架构与开发约定

浏览器 / React→FastAPI 路由→业务服务→数据库 / 外部服务
  • 前端：React、TypeScript、Vite 和 Ant Design；页面与业务能力分目录组织。
  • 后端：FastAPI 提供版本化 API，按业务域组织路由、服务、模型及数据结构。
  • 持久化：平台主库使用 PostgreSQL，表结构变更通过 Alembic 管理。
  • 外部依赖：模型服务、通知、ASR 等能力依赖相应配置和运行环境，部署时应分别确认。
