# SuperAgent 优化实施方案

**目标**：让管理员看到的配置、运行时采用的配置、任务结束后可追溯的证据一致。优先修复会改变结论或误导操作者的问题，再根据实测决定检索调优和页面改版的范围。

**审查基线**：2026-11-25，审查时提交为 `4881117`，工作区另有在途修改。下列编号沿用前次审查，分批顺序按影响和依赖排列。#1–4 已用隔离样例复现，#5–14 来自代码路径核对。运行质量、延迟和模型效果尚无生产实测数据。实施时在当前工作树复核，已修项保留验证证据即可。

## 运行链路和改动边界

| 链路 | 应保留的行为 | 本次切入点 |
|---|---|---|
| 通用任务 → Planner → 子 Agent → 方案 | 运行快照、独立授权、输入指纹、重试、成功检查点 | 检索问题、Skill 文件和子 Agent 输出验证 |
| 用例生成 → 模块 WorkItem → 汇总审核 → 草稿 | 模块独立执行、租约、预算、人工审核 | 复用有效 Skill 表示，覆盖同步入口和异步 Worker |
| 上传 → 文档版本 → Chunk → 索引代 → 查询 → 引用 | 固定版本、查询时复核权限、索引切换和回滚 | 分块边界、候选规模、索引排队和证据诊断 |
| 工具与 MCP → 调用事实 → 管理页 | 服务端身份、停用检查、只读审批、审计脱敏 | 显示间接依赖，记录治理拒绝 |

### 前端交付范围

1. **Agent 管理**：默认按主子关系浏览，保留独立 Agent。首层展示职责、启用状态、实际模型与配置异常。详情提供“有效配置”，能看到当前路径采用的 Skill 文件、知识范围、工具及来源。
2. **知识库**：按“资料与版本 → Agent 范围与试搜 → 索引与模型”组织内容。分别显示解析状态、向量覆盖和检索降级。结果可定位文档版本、页码或片段。保留索引代切换与回滚入口。
3. **治理与质量**：Skill、MCP、工具详情可解释依赖关系。质量页可从异常进入已有任务详情，看到检索、子 Agent、工具和审核记录。没有采集的字段显示未知。
4. **页面验收**：复用 `frontend/e2e/all-routes-responsive.spec.ts` 的路由与视口清单。13 个管理入口做导航、标题与基本状态冒烟；对本次改动页面在 1440×900 和 390×844 实际操作。重点走完“配置范围 → 试搜 → 查来源”和“查看运行异常 → 定位对应事件”。检查加载、空态、错误、重试和迟到响应。截图与测试数据标注本次版本。

## 检索与重排的评测决策

准备脱敏题集，包含中文业务规则、API 字段、错误码、中英混合、跨段约束、相似旧版本、无答案和权限负例。每题标注项目、Agent、可见版本、预期来源与可回答性。同一语料、权限、索引版本及 Top-K 下比较 BM25、向量、RRF、RRF＋重排和 BM25 降级后重排。记录实际生效策略、模型版本和窗口大小。

| 要回答的问题 | 记录指标 | 决策 |
|---|---|---|
| 正确证据是否进入候选？ | Recall@K、无命中率、完全重复块比例 | 对未召回题先看查询、切块和候选截断。 |
| 重排是否改善前几名？ | MRR 或 nDCG@K、每题正确证据重排前后名次 | 分别校准融合阈值和模型重排阈值，保留回退基线。 |
| 最终答案是否采用正确证据？ | 引用支持率、无答案题误答率、越权来源数、盲审样例 | 越权来源数必须为零；留存失败题和错误阶段。 |
| 收益是否抵得上代价？ | P50/P95 耗时、降级率、模型调用数、可计价成本 | 报告样本量及同题差值，再决定是否调整默认模型、窗口或切块策略。 |

工程桩用于验协议、权限、排序和降级。真实模型效果需要授权的模型与标注语料；缺少条件时交付可复跑评测入口、样例和未验证项，保留当前默认策略。
