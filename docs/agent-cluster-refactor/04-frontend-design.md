## 前端改造

### 保留业务导航，新增智能工作区

保留原有管理页面、路由、权限与菜单分组，新增全局任务、Agent 配置、Skills、工具/MCP 和文件中心。LLM 入口复用现有模型资源；凭据和供应商配置沿用管理员权限，项目用户只管理被允许的角色绑定。

Agent 配置页面管理模板与版本；当前运行的实例在任务详情中查看，避免把“模板数量”当作“在线 Worker 数量”。

### 全局任务列表

参考截图的列表交互，展示名称、目标摘要、项目、状态、当前阶段、活跃 Worker、更新时间、运行时长与实际用量。支持搜索、状态过滤、创建、打开、暂停、取消、重试和归档；归档不删除运行证据。

进度采用已完成子任务数/已确定子任务数及当前阶段。规划未完成时不展示虚构百分比。用量缺失显示“未知”，不伪装为零；Token、模型耗时及可估算成本按实际调用汇总。

### 任务详情：截图中两块区域的落地

左侧为参与者/会话列表：任务主 Agent、Planner、系统事件、专业 Workers、审阅/报告角色。每个 Worker 显示角色、实例 ID、状态、子任务摘要以及待答复标记。同一职责的多个 Worker 独立列出。

右侧随选择切换：执行摘要、消息、可展开的工具调用参数与结果、等待原因、模型配置、实际用量、附件与产物。系统事件是只读审计时间线。展示行动与结果，不要求存储或展示模型隐藏推理。

输入区明确标注“发给任务主 Agent”或“发给 API Worker W-xxx”；状态操作与对话输入分开。切换参与者不混合会话历史。浏览器刷新后能按服务端状态恢复。

任务级 Tabs 首批提供“会话、方案、产物、运行记录”，后续按实际接入增加报告和审阅视图，不照搬未实现标签。

### 全局调度抽屉

挂在 ConsoleLayout 的路由出口之外，配合 GlobalAssistantProvider 保留会话、选中任务及展开状态。支持创建、查询、跟踪任务与跳转任务详情。

当前页面可提供 ContextRef（项目、资源类型、ID、版本及用户选中项）。只在用户选择引用时携带业务内容；未保存表单不被自动视为已保存资产。

切换项目时不改变已创建任务的项目，也不把新页面资源偷偷加入旧任务。抽屉显示正在处理任务的固定项目；新请求可以显式新建另一项目任务。跨项目总览始终按当前用户可见范围过滤。

桌面支持可收起的右侧抽屉，关闭后任务继续运行；复杂协作在任务详情中展开。窄屏使用全屏抽屉，参与者列表折叠为选择器，关键操作保持可访问。

### 配置编辑体验

Agent：角色、目标、模型、指令、Skills、工具、资源范围、预算与输出要求。

Skill：名称、适用场景、步骤说明、输出要求、版本及启用状态。

Tool：平台适配器或 MCP/HTTP 接入配置、输入/输出 schema、副作用类别、权限、超时、幂等与取消能力。AI 起草的是定义与配置，不会凭空获得未实现的执行能力。

提供“描述需求 → AI 起草 → 编辑 → 校验 → 保存草稿 → 发布版本”。角色和工具扩大权限不能由 AI 自行批准。新配置版本只影响新运行或显式采用该版本的后续计划。
