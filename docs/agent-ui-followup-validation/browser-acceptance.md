## 响应式测量

容器/document 的 `scrollWidth` 与 viewport 宽度一致，未出现页面横向溢出。

| CSS viewport | 验收布局 |
| --- | --- |
| 1440 × 900 | 会话列表 220px、聊天区 596px、结果详情 320px，三栏可见。 |
| 1024 × 900 | 会话列表收起，聊天区约 412px 与 320px 结果详情并排。 |
| 768 × 900 | 单列工作区，使用面板标签在会话与结果间切换。 |
| 390 × 844 | 移动单列布局，面板标签和结果操作仍在视口内。 |

Agent 工作台主流程在桌面宽度实际查看了会话、结构化计划/结果、人工确认入口与执行结果入口。四个宽度完成的是布局/溢出与主要面板可达性验收；未在每种宽度重复调用完整生成与执行链路。

## 截图归档限制

浏览器截图曾在验收会话中捕获并显示，用于观察四种 viewport。尝试将截图导出为项目文件时，浏览器安全策略拒绝该动作，并明确要求不得通过其它途径、间接执行或备用浏览器表面绕过。遵守该限制后，本目录只保存尺寸和行为记录，没有截图二进制文件。最终交付将仓库截图归档列为未完成阻塞；不把截图标记成已归档。
